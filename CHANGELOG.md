# История изменений

## [0.6.0] - 2026-11-05

- `pob_tree_icons`: оригинальные иконки текущего дерева из Lua, до 32 имён за запрос, PNG RGBA с прозрачностью. Все 524 иконки закреплённого дерева проверяются настоящим Lua. Имена не позволяют читать посторонние файлы.
- Переносимое декодирование DDS BC1 без Direct3D/GDI; Linux/macOS native-архивы включают закреплённый Zstandard 1.5.7 с лицензией BSD.

## [0.5.2] - 2026-11-05

- Компактное настоящее дерево Lua через `pob_get_tree`: узлы, связи, выбранные состояния, версия и очки для собственного интерфейса Flutter.
- Проверка готового Windows ZIP проверяет наличие инструмента геометрии без устаревшего ограничения числа инструментов. Тег 0.5.1 также был остановлен CI до публикации.

## [0.5.1] - 2026-11-05

- Выпущен публичный `pob_get_tree` с компактной геометрией настоящего дерева Lua для Flutter: узлы, связи, выбранные состояния, версия и очки. Работает без PNG на Windows/Linux/macOS.
- Проверки обнаружения MCP учитывают новый инструмент. Тег 0.5.0 был остановлен CI до публикации пакетов.

## [0.5.0] - 2026-11-05

- Публичный `pob_get_tree` возвращает компактную геометрию настоящего дерева из Lua: координаты, связи, типы и имена узлов, выбранные узлы, версию и строку очков. Работает без PNG и Direct3D на всех платформах `engine`.
- Геометрия предназначена для собственного интерфейса; игровые действия и проверка допустимости остаются в Lua.

## [0.4.1] - 2026-11-05

- Диагностика `engine` возвращает фактическую платформу: `windows-engine`, `linux-engine` или `macos-engine`; историческая метка Windows больше не показывается на других ОС.
- Исправлен порядок аргументов в инструкции запуска `doctor` на Linux/macOS.

## [0.4.0] - 2026-11-05

### Добавлено

- Настоящий Lua в режиме `engine` на Linux x64 и macOS Apple Silicon. Исходные игровые формулы не изменены и не перенесены в Python.
- Отдельные архивы LuaJIT и lua-utf8, собранные из закреплённых ревизий с исходными лицензиями. Установка библиотек в систему не требуется.
- CI запускает диагностику, создание и изменение сборки, расчёты, XML и MCP stdio с исходным PoB на Windows, Linux и macOS.
- Публикация обоих нативных архивов с SHA-256 вместе с wheel и Windows ZIP.

### Ограничения

- PNG-отрисовка через GDI/Direct3D и режим управления оригинальным окном PoB остаются возможностями Windows. Перенос касается отдельных расчётов Lua (`engine`).
- Для Linux/macOS требуется Python 3.11+ соответствующей архитектуры. Архивы: Linux x64 (Ubuntu 22.04+) и macOS arm64 (11+).

## [0.3.0] - 2026-11-05

### Добавлено

- Инструмент `pob_render_image`: PNG сводки, схемы дерева, всех характеристик, предметов, камней, условий расчёта, заметок, предупреждений и полного отчёта. Отдельные предметы и узлы доступны по ID; длинные отчёты разбиваются на страницы.
- Изображения возвращаются блоками MCP `image` в обоих режимах; Windows GDI и кодировщик PNG не требуют дополнительных пакетов. Согласованный снимок Lua сохраняет исходную сборку и ревизию.
- Дерево воспроизводит оригинальный `PassiveTreeView:Draw` через Direct3D 11 WARP: DDS BC1/BC7 и PNG, пропорциональный масштаб иконок, рамки, фоны, свечение и дуги. Добавлен `zoom`; подписи по умолчанию скрыты. Служебные связи с восхождением не рисуются.
- В режиме `app` изображения дерева формируются по XML в отдельной сессии Lua; ради отрисовки не требуется изменять файлы установленного PoB или обновлять его мост.

### Исправлено

- Режим `app` восстанавливает соединение после закрытия или перезапуска PoB без перезапуска MCP-сервера. Запрос чтения при обрыве повторяется не более одного раза с актуальными адресом, токеном и ревизией.
- Команды изменения при потере ответа не повторяются; следующий запрос использует новое соединение.
- Закрытие соединения после тайм-аута больше не ждёт заблокированный читающий поток.

## [0.2.0] - 2026-11-05

### Добавлено

- Готовый Windows ZIP со встроенным Python: отдельная установка Python, pip и Git для работы с установленным PoB не нужна.
- Автоматический поиск обычной установки PoB по реестру и стандартным каталогам; поддержка portable-каталога и исходного репозитория.
- Режим `app`: чтение и изменение текущей сборки в настоящем окне PoB через локальный Lua-мост.
- Команды установки и удаления моста с резервной копией `Launch.lua`, а также готовая настройка обоих MCP-серверов через `config`.
- Обнаружение ручных правок, проверка ревизии, защита несохранённой сборки при замене и блокировка изменений при открытом диалоге.
- Автоматическая публикация релиза по тегу: проверки, сборка wheel и ZIP, описание из changelog и SHA256SUMS.

### Изменено

- `setup` загружает движок из официального `PathOfBuildingCommunity/PathOfBuilding-PoE2`.
- Режим `engine` использует уже установленный PoB без повторного скачивания движка.
- API совместим с конструкторами классов стабильной PoB 0.23.1 и закреплённой ветки разработки.
- Фоновый процесс использует включённые headless-определения, не читает личные настройки и не записывает файлы установленного PoB.

### Исправлено

- Ошибки создания предметов и чтения подсказок узлов на стабильной версии PoB.
- При откате ошибочной операции сохраняются имя, путь файла и признак несохранённых изменений текущей сборки.
- Отсутствующие в версии PoB заметки узлов возвращают явную ошибку неподдерживаемой операции.

## [0.1.0] - 2026-11-05

- MCP выделен в отдельный устанавливаемый Python-пакет с 13 инструментами.
- Добавлены установка из GitHub, отдельная загрузка движка и диагностика `doctor`.
- Сохранены исходные лицензии и документация API.
- Добавлены проверки настоящего Lua, MCP stdio, импорта и экспорта XML.
