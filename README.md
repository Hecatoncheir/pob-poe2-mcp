# PoB PoE2 MCP

Локальный MCP-сервер для **Path of Building — Path of Exile 2**. Позволяет ассистенту создавать сборки, выбирать камни и предметы, менять дерево и условия боя, получать расчёты и экспортировать XML. **Все игровые расчёты выполняют исходные классы Lua из PoB.**

Сервер выделен из [Hecatoncheir/PathOfBuilding-PoE2](https://github.com/Hecatoncheir/PathOfBuilding-PoE2/tree/b565cd99ec9fad46167bc4de145d3491b9c669e7/app/tools). Flutter и запуск графического приложения не требуются. Сторонних зависимостей во время работы Python-сервера нет.

## Требования

- Windows x64 и 64-разрядный Python 3.11 или новее.
- Git — для установки из GitHub и команды `setup`.
- Lua-движок PoB: можно загрузить командой `setup` или указать существующий каталог с `src/` и `runtime/`.

Linux/macOS, PoE 1 и удалённый HTTP MCP в этой версии не поддерживаются. Каталог установленной графической версии PoB может иметь другую структуру; нужен именно каталог с `src/HeadlessWrapper.lua` и `runtime/lua51.dll`.

## Установка из GitHub

Команды для PowerShell:

```powershell
python -m venv "$HOME/.venvs/pob-poe2-mcp"
$pobPython = "$HOME/.venvs/pob-poe2-mcp/Scripts/python.exe"
& $pobPython -m pip install "git+https://github.com/Hecatoncheir/pob-poe2-mcp.git@v0.1.0"
& $pobPython -m pob_poe2_mcp setup
& $pobPython -m pob_poe2_mcp doctor
```

Установка пакета использует [setuptools](https://setuptools.pypa.io/en/stable/) как средство сборки; pip устанавливает его в изолированное окружение сборки. Для самого сервера дополнительные Python-пакеты не нужны.

`setup` загружает только рабочие каталоги `src/`, `runtime/` и корневые файлы из закреплённой ревизии PoB. Каталог по умолчанию: `%LOCALAPPDATA%/pob-poe2-mcp/engines/<revision>`. Сетевой доступ нужен для этой загрузки; при обычных вызовах MCP сервер сам ничего не скачивает. Существующий каталог `setup` не перезаписывает.

Можно использовать свой путь:

```powershell
& $pobPython -m pob_poe2_mcp setup --destination C:/Tools/PoB-engine
& $pobPython -m pob_poe2_mcp doctor --pob-dir C:/Tools/PoB-engine
```

Для уже имеющегося совместимого репозитория загрузку можно пропустить:

```powershell
& $pobPython -m pob_poe2_mcp doctor --pob-dir C:/code/PathOfBuilding-PoE2
```

`doctor` запускает настоящий Lua и читает каталог классов. Признак успешной проверки — `"ok": true` и код завершения 0. Диагностика Lua, в том числе сообщения исходного дерева `missing node`, выводится в stderr; успех диагностики запуска не означает отсутствие предупреждений в конкретной сборке.

## Подключение MCP

Пример для локального клиента, поддерживающего запуск MCP по stdio:

```json
{
  "mcpServers": {
    "pob-poe2": {
      "command": "C:/Users/YOUR_NAME/.venvs/pob-poe2-mcp/Scripts/python.exe",
      "args": ["-m", "pob_poe2_mcp", "serve"]
    }
  }
}
```

Замените `YOUR_NAME` своим именем пользователя. Укажите абсолютный путь к Python из созданного окружения. После стандартного `setup` параметр каталога движка не нужен. Для собственного каталога добавьте `"--pob-dir", "C:/Tools/PoB-engine"` в `args` или задайте переменную окружения `POB_DIR`.

Приоритет выбора движка: `--pob-dir`, затем `POB_DIR`, затем стандартный каталог `setup`. Рабочий каталог клиента может быть любым. Доступен также исполняемый файл `pob-poe2-mcp.exe` из `Scripts/` окружения.

Транспорт — JSON-RPC 2.0, одна строка UTF-8 на сообщение. stdout содержит только ответы протокола, stderr — диагностику. Без запросов сервер ожидает ввод. `initialize` и список инструментов доступны до установки движка; первый игровой вызов потребует Lua. Поддерживаются версии MCP `2024-11-05`, `2025-03-26`, `2025-06-18`, `2025-11-25`.

Обычный облачный чат не получает доступ к локальному stdio автоматически: нужно приложение, которое подключит этот процесс как MCP. Каждый процесс хранит свою сборку в памяти; с открытым окном PoB она автоматически не синхронизируется. Для переноса результата используйте XML.

## Запуск из клона без установки пакета

```powershell
git clone https://github.com/Hecatoncheir/pob-poe2-mcp.git
cd pob-poe2-mcp
python -X utf8 run.py setup
python -X utf8 run.py doctor
python -X utf8 run.py serve
```

Для MCP в этом варианте задайте `command` с абсолютным путём к Python, а `args` — `["-X", "utf8", "C:/code/pob-poe2-mcp/run.py", "serve"]`. Можно передать `--pob-dir` после `serve`.

## Инструменты

| Инструмент | Назначение |
| --- | --- |
| `pob_catalog` | Каталоги классов, камней, баз предметов, слотов, узлов дерева и условий; поиск и страницы. |
| `pob_create_build` | Создание сборки с классом и уровнем. |
| `pob_import_xml` | Импорт полного XML `PathOfBuilding2`. |
| `pob_add_skill_group` | Добавление группы камней. |
| `pob_add_item` | Разбор игрового текста предмета и установка в слот. |
| `pob_set_config` | Условия расчёта. |
| `pob_set_custom_mods` | Пользовательские модификаторы. |
| `pob_tree_action` | Назначение и возврат узлов, атрибуты, заметки. |
| `pob_tree_options` | Класс, восхождение, оружейный режим, набор дерева. |
| `pob_select_main_skill` | Выбор основного умения. |
| `pob_node_tooltip` | Подсказка узла и изменения расчётов. |
| `pob_check_build` | Подробный отчёт, предупреждения и проверка числовых целей. |
| `pob_export_xml` | Экспорт полного XML. |

[Схемы инструментов](pob_poe2_mcp/data/tools.json) · [Описание API и порядок работы](docs/api.md) · [Пример Python API](examples/build_fireball.py).

Сначала читайте каталоги, затем создавайте или импортируйте сборку. Проверяйте `warnings`, ошибки камней, неподдержанные модификаторы и условия `config`. Успешный расчёт или выполнение числовых целей означает проверку в PoB; проверка в игре, стоимость и доступность предметов сюда не входят. Share-коды, торговля, импорт аккаунта и удалённый HTTP-транспорт не реализованы.

## Версия движка

Совместимая ревизия закреплена в [engine-lock.json](pob_poe2_mcp/data/engine-lock.json):

```text
Hecatoncheir/PathOfBuilding-PoE2
b565cd99ec9fad46167bc4de145d3491b9c669e7
дерево 0_5
```

Это воспроизводимая база расчётов, которая не обновляется автоматически до последних данных игры. Другие ревизии можно указать через `--pob-dir`, но их совместимость нужно проверять отдельно. Поставляемая таблица размеров изображений соответствует указанной ревизии дерева; сами изображения и Flutter-ресурсы в пакет не входят.

## Разработка и проверки

```powershell
$env:POB_DIR = "C:/code/PathOfBuilding-PoE2"
python -X utf8 -m unittest discover -s tests -v
python -X utf8 examples/build_fireball.py --pob-dir $env:POB_DIR
```

Без доступного движка проверки настоящего Lua пропускаются; проверки транспорта и настроек выполняются. Windows CI отдельно загружает закреплённый движок и выполняет полный набор, включая создание сборки, предметы, камни, дерево, откат ошибок, XML и MCP stdio. Игровые формулы остаются в Lua.
